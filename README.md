# Blinkit-Analysis

#Blinkit Grocery Sales Analysis Dashboard
#Overview:
This repository contains an interactive Power BI dashboard designed to analyze grocery sales performance for a quick-commerce business. The dashboard provides insights into sales trends, outlet performance, product categories, customer preferences, and ratings, enabling data-driven business decisions.

#Dashboard

#Grocery Sales Analytics Dashboard

Aim: Provide business stakeholders with a comprehensive view of sales performance across products, outlet types, outlet locations, and customer preferences to support operational and strategic decision-making.

Key Visuals:
KPI Cards → Total Sales, Average Sales, Number of Items, Average Rating
Donut Chart → Sales Distribution by Fat Content (Low Fat vs Regular)
Bar Chart → Sales by Item Type
Area Chart → Sales by Outlet Establishment Year
Donut Chart → Sales by Outlet Size
Funnel Chart → Sales by Outlet Location Tier
Bar Chart → Fat Content Analysis by Outlet Location
Matrix/Table → Outlet Type Performance Analysis


Filters:
Outlet Location Type
Outlet Size
Item Type


#Insights Delivered:
Identified top-performing product categories, outlet types, and outlet locations driving overall sales.
Evaluated customer preferences across product segments and analyzed sales contribution by fat-content categories.
Enabled data-driven decisions through sales, rating, and outlet performance analysis.

#Tech Stack
Power BI → Power Query, DAX measures, interactive dashboards
Data Sources → BlinkIT Grocery Data
